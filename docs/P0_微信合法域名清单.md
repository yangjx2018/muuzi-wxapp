# P0 微信合法域名清单

> 配置位置：**微信公众平台** → **开发** → **开发管理** → **开发设置** → **服务器域名**  
> 入口：https://mp.weixin.qq.com/

## 这是在配什么？

是的：小程序真机 / 打开「校验合法域名」后，`wx.request` / `uploadFile` / `downloadFile` / `WebSocket` **只能访问这里登记过的域名**。  
未登记时开发者工具可关校验联调，**提审与真机正式环境必须登记**。

注意两套「白名单」别混：

| 名称 | 在哪 | 作用 |
|------|------|------|
| **微信服务器域名** | 微信公众平台后台（本页） | 允许小程序发 HTTPS/WSS 请求 |
| **节点选择白名单** | `miniprogram/config.js` → `NODE_WHITELIST` | 登录页可选哪些 GuDuu 节点 |

`www.muuzi.co` 是官方 Platform（段 B），**不是登录节点**；只进微信 request 域名，不进节点选择器。

## 后台怎么点（你已登录时）

1. 打开 https://mp.weixin.qq.com/ ，选中**本小程序**账号（不是公众号）。
2. 左侧：**开发** → **开发管理**。
3. 顶栏切到：**开发设置**。
4. 找到 **服务器域名** → 点 **修改**（可能要扫管理员码）。
5. 按下面四类分别填入（**只填主机名**，不要 `https://`，不要末尾 `/`，不要路径）。
6. 保存。每月修改次数有限，一次填齐。

官方说明可参考：[服务器域名配置](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)。

### socket 合法域名（WSS）

Matrix sync 走节点时需要（Platform 一般不需要）：

```
im.muuzi.co
dev-os.guduu.co
guduuos.com
```

### uploadFile / downloadFile 合法域名

与 request 相同四条即可：

```
im.muuzi.co
www.muuzi.co
dev-os.guduu.co
guduuos.com
```

### 业务域名（web-view）

「打开主页 / 看成品」进入 `pages/me/open-home`。仅当 **微信后台已登记业务域名** 且 **`miniprogram/config.js` 的 `WEBVIEW_BUSINESS_HOSTS` 含该主机** 时才挂 web-view；任一为空则走复制链接回退（避免「无法打开该页面」系统页）。

建议登记（与后台一致后再写入 `WEBVIEW_BUSINESS_HOSTS`）：

```
im.muuzi.co
www.muuzi.co
```

体验版默认两边都留空（见 `docs/R_体验版提审材料.md`）。Studio 认证外链仍用复制链接，不做 web-view。

## 填写格式（易错）

| 错误写法 | 正确写法 |
|----------|----------|
| `https://im.muuzi.co/` | `im.muuzi.co` |
| `im.muuzi.co/cosmac/...` | `im.muuzi.co` |
| `127.0.0.1` / 内网 IP | **不能**进正式服务器域名；本地请关「校验合法域名」 |

域名须已备案、HTTPS 有效；校验失败时后台会提示，按提示修证书/备案后再保存。
