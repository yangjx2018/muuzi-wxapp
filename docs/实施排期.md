## 0. 怎么用这份排期

1. **双轨并行**：轨 A = `MuuziWx` 小程序；轨 B = `GuDuuOS/GuDuu-OS` 契约 A。  
2. **真值**：行为以 `MuuziGit/muuzi` 为准；边界以 `MuuziWx/docs` 为准。  
3. **人天为估**：按 1 名熟悉前端的主程 + 0.5 名节点后端兼岗估算；可按人力倍增压缩日历。  
4. **门禁**：每阶段对照 `验收文档.md` 对应里程碑签字后再进下一阶段。
