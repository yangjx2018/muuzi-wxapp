**对应**：`PRD.md`、`SDD.md`（v1.1）  
**范围**：登录(M0，含微信登录) → 连接(M1) → 我(M2) → 消息(M3)

## 0. 验收总则

### 0.1 通过标准

某一里程碑 **通过** 当且仅当：

1. 该阶段「必须」用例全部 Pass；  
2. 与同账号手机 App 对照：关键数据一致；  
3. 无「假成功」；  
4. Blocker/Critical = 0；Major 须书面豁免。

### 0.2 环境

| 项 | 要求 |
|----|------|
| 小程序 | 开发版/体验版，真实 AppID |
| 后端 | 与手机 App 相同 Platform + 可测节点 |
| 对照设备 | 同 `user_id` 的 MuuZi App |
| 账号 | ≥2 节点用户；访客机（Join）；微信测试号 |
| 网络 | 正常 / 断网 / 弱网 |

### 0.3 缺陷级别

| 级别 | 定义 |
|------|------|
| Blocker | 无法登录/进入模块、登录态损坏、写错账号 |
| Critical | 主路径不可用 |
| Major | 重要子功能失败或严重 UI 偏离 |
| Minor | 文案微调、间距 |

### 0.4 UI 1:1

登录页对照图 A / App `LoginScreen`：结构、文案、节点卡、主按钮一致；**仅**「或使用其他方式」下方为微信而非 Apple/Google。

## 1. 里程碑 M0 · 登录（硬前置）

### 1.1 登录页 UI

| 编号 | 用例 | 期望 | 级别 |
|------|------|------|------|
| A-L-01 | 冷启无会话 | 进入登录页，非业务 Tab | Blocker |
| A-L-02 | 品牌区 | Logo、MuuZi、`// 主理人入口`、会话态/设置入口 | Major |
| A-L-03 | 步骤与标题 | `AUTH / 001`、「登录 MuuZi」、导语一致 | Critical |
| A-L-04 | 法律说明 | 含「只会送往你选择的 GuDuu OS 节点，不会送往 Nexus」 | Critical |
| A-L-05 | 底栏状态 | 无节点 `NODE / REQUIRED`；有节点 `NODE / READY` | Major |
| A-L-06 | **无 Apple/Google** | 第三方区不得出现 Apple、Google 按钮 | Critical |
| A-L-07 | 微信入口 | 「或使用其他方式」+「微信登录」可见 | Critical |

### 1.2 节点与密码登录

| 编号 | 用例 | 期望 | 级别 |
|------|------|------|------|
| A-L-10 | 未选节点 | 主按钮不可用 / 无法提交 | Critical |
| A-L-11 | 更换节点 | 可选并回显域名 | Critical |
| A-L-12 | 账号密码成功 | 进入业务默认页；Session 持久 | Blocker |

| A-L-14 | step-up | 出现 6 位码；按钮「完成安全验证」；完成后进业务 | Critical |
| A-L-15 | 忘记密码 | 进入找回流程并可返回登录 | Major |
| A-L-16 | 建立新账号 | 进入注册流程 | Major |

### 1.3 微信登录

| 编号 | 用例 | 期望 | 级别 |
|------|------|------|------|
| A-L-20 | 未选节点点微信 | 不可完成登录；提示选节点 | Critical |
| A-L-21 | **微信登录主路径** | `wx.login` → 换票 → beginSession → 业务页；与 App 同节点身份体系 | **Blocker** |
| A-L-22 | 换票失败 | 网络/拒绝/无效 code 有明确错误；**不得**半登录进 Tab；**不得**用「功能未开放」代替未实现 | Critical |
| A-L-23 | 需绑定已有账号 | 绑定完成前不进业务 Tab；绑定后可互通 | Critical |
| A-L-24 | code 泄露防护 | 日志/分享路径无明文 code/token | Critical |
| A-L-25 | 再冷启 | 微信登录会话可恢复（与密码会话同等存储） | Critical |
| A-L-26 | 无微信则 M0 失败 | 仅有密码登录、无真实微信换票 → **M0 不通过** | Blocker |

### 1.4 注册 / 找回主路径

| 编号 | 用例 | 期望 | 级别 |
|------|------|------|------|
| A-L-30 | 注册三步 | 邮箱→验证码→设密→可登录 | Critical |
| A-L-31 | 找回三步 | 同结构；成功后用新密码登录 | Critical |

### 1.5 拦截

### 4.1 附件真机步骤（A-N-23）

同账号、**明文房间**：

1. 小程序发图片 → App 可见并可打开  
2. App 发图片 → 小程序会话内预览  
3. 小程序发短视频（≤60s）→ App 可播放  
4. 小程序发 PDF/文件 → App 可识别；反向 App→小程序 文件可「点击打开」  
5. 加密房间点附件 → 诚实提示，不假成功

## 6. 平台差异登记表

| 差异点 | App | 小程序方案 | 结果 |
|--------|-----|------------|------|
| 第三方登录 | Apple / Google | **微信登录**；导航 **三 Tab**；段 A=**所选节点**；同节点一微信号一账号、跨节点可绑 | **工程已落地**（本地 bot 产品验收 2026-09-21；公网契约 A 仍并行） |
| 微信换票端点 | — | **用户所选节点**（非集中 Identity） | **工程已落地** · `wechat-login` → 当前节点 |
| 语音采集 | FieldAudioBridge | RecorderManager + AAC→M4A；拒权诚实文案 | **工程已落地** · 手感见 `R_已知问题` K-10 |
| Matrix 运行时 | matrix-js-sdk | **方案 A：小程序内自研 `/sync` 客户端** | **工程已落地** · M3.1–M3.7 |
| E2EE | Web crypto | **首期 A**：明文互通 + 失败诚实提示；全量密钥恢复后续 | **工程已落地（首期）** · 完整恢复见 K-02 |
| 会员支付 | Apple IAP 等 | **微信小程序 JSAPI**（createOrder + wechat）；未配置诚实失败 | **工程已落地** · 商户号待配见 K-12 |
| Studio | 系统浏览器/外链 | **复制链接**（提示浏览器/电脑打开；无 web-view） | **工程已落地** · `studioLinks` |
| 动态节点域名 | 任意用户节点 | **首期白名单节点 only** | **工程已落地** · `NODE_WHITELIST` |
| 导航 | 五 Tab | **三 Tab：连接·消息·我**；登录固定进连接 | **工程已落地** |

详细韧性/回归勾选见 `docs/R_韧性与回归清单.md`；已知延后见 `docs/R_已知问题.md`。
